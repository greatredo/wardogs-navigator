# WARDOGS Navigator

用于 WARDOGS 地面载具的本地 Windows 导航工具：屏幕小地图定位、局内大地图叠加与快捷键导航、分类绘路、行驶路线记录、完整路线收藏、框选危险区绕行、连续往返、常规与拉力赛图标和离线语音。内置 **OZETI、BAKURANI、ZESTAFONA** 三张地图，当前版本 **0.7.1 测试版**，界面语言为中文。

原创程序代码和文档采用 [Apache-2.0](LICENSE)。地图素材与第三方组件的权利范围见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。本项目为非官方工具，尚未取得游戏方对在线使用或分发的明确批准；开源许可证不代表游戏方许可。

## 启动

解压整个 `WardogsNavigator-Windows-x64.zip`，双击文件夹内的 `WardogsNavigator.exe`（或 `启动导航.cmd`）。保留同目录 `_internal` 文件夹，无需安装 Python。目标平台为 Windows 10/11 x64。

启动后直接进入地面导航。

设置和属性窗口中的数值、下拉选项不再响应滚轮改值；请直接输入、点击箭头或选择选项。滚轮仍可滚动页面和缩放地图。

## 第一次使用

1. 在窗口顶部选择当前游戏地图。**先保持游戏当前的全屏模式**，小地图固定北朝上。建议使用能看清周围道路和地形的小地图缩放等级。附带的 `定位诊断样例.png` 是公开底图裁剪，仅用于图片定位自检，不是游戏截图或推荐缩放设置。
2. 点击“框选小地图”，选择对应显示器，在屏幕静态预览中框出地图画面。采集坐标使用物理像素，支持不同显示器与 DPI。只框地图内容，避免边框与其他 HUD。玩家箭头默认位于截取区域中心；位置偏移时在“设置”调整锚点 X/Y 百分比。
3. 点击“开启定位”，确认位置落在实际地形上。可以先用“设置 → 用图片检验定位”选择小地图截图，离线核对算法；图片检验不会启动实时导航。
4. 在总地图点选目的地。起始点可用“地图设置起点”、右键地图或“使用当前位置”设置，蓝色标记可拖动；起始点也是往返的返程终点。未设置时，点击“开始导航”并取得有效实时定位后会自动放在当前位置；已有起始点不会被覆盖。启用需要的道路分类后开始导航。目的地可收藏并重新选择；已有起始点时，无需定位也能预览完整路线。
5. 需要绕行时，点击**“框选危险区”**，按住鼠标拖出矩形。路线自动避开穿过矩形的路段；拖动中心可移动区域，拖右下角可改大小。道路不连通时明确提示，不会补一条跨越未知地形的直线。
6. 也可以添加途经点并拖动，路线按顺序经过这些点。连续往返会在到达后提示掉头，切换去程/返程。途中修改目的地不会改变起始点；去程中修改起始点可调整之后的返程终点，返程中修改则立即重算当前返程。导航继续从车辆当前位置出发。起始点随当前地图的配置保存，支持撤销和导入导出；驾驶由玩家操作。
7. 实时导航时，路径默认叠加在游戏小地图上：淡色为本程完整路线，亮色为剩余路程，会随前进缩短；往返换向后按新的行驶方向显示。主窗口可以最小化，独立图标和路径继续显示；定位丢失或停止导航时路径隐藏。

每局重设路线时，可在第一页 **“导航 → 目的地与途经点”** 或 **地图上方工具栏** 点击“清空途经点”“清空危险区”。两个按钮分别清除当前地图的对应内容，保留目的地、道路和收藏；清空后自动重新规划，可用顶部“撤销”或 Ctrl+Z 恢复。没有相应内容时按钮变灰。

结束本次行程时，在上述两个位置点击 **“清除当前路线”**：停止导航和播报，清除当前地图的起始点、目的地、全部途经点、路线预览和小地图路径，并退出当前载入的收藏及本次往返行程。导航图标保持原来的显隐状态；原本显示时会提示“路线已清除”。清除结果会自动保存，重新启动不会带回旧端点；已保存的道路、目的地收藏、路线收藏、路书、危险区和路线规则保留。误点可撤销恢复行程设置，恢复后需手动开始导航。“停止”只暂停导航并保留路线预览；想收掉旧路线时使用“清除当前路线”。

## 地图与道路编辑

- **顶部地图选择框**切换 OZETI、BAKURANI、ZESTAFONA。切换会先保存当前地图，载入新地图的道路、收藏、路书、危险区、目的地和比例尺，清除旧定位与路线并停止播报。重新开启定位、开始导航即可继续；下次启动记住上次选择。后台只保留当前地图的定位特征。
- 三图使用无队友标记的公开底图。0.5.3 纳入维护者于 2026-09-19 手动完善的路网：OZETI 248 条、BAKURANI 266 条、ZESTAFONA 206 条，保留大路、小路和野地分类。初始路网由图像提取及部分连接修正生成，现可继续手动完善；覆盖范围和实际通行性仍需结合游戏确认。
- 首次使用会载入新版内置道路。已有配置会继续保留；需要采用新版路网时，先选对应地图，再到 **“地图标注 → 载入内置路网”** 确认。此操作替换该图全部道路，保留路线收藏、目的地、途经点、危险区、路书和规则，自动备份原配置并支持撤销。三张图需分别操作；已有自绘道路想继续保留时，先用“导出路网”单独备份，再按需合并导入。
- 金色为大路、蓝色为小路、浅绿色为野地/越野；地图上的道路统一采用 0.5.0 中未确认道路的虚线样式，仅作为显示风格，不再区分确认状态。主图与游戏小地图的导航路线保持原来的实线样式。三张图都支持同样的自动规划、补绘、收藏和路书功能。
- 道路保存或导入后直接按分类参与规划，无需设置确认状态。旧配置的“仅实测”筛选不再生效，旧道路和几何坐标保留。配置格式保留兼容字段，不代表实际通行性已经验证；分享时在配置说明中写清游戏内测试范围。
- **“导航 → 道路偏好”** 为每类道路选择“优先 / 正常 / 尽量避开”。规划会综合距离与偏好，必要时仍可经过非首选道路接驳，不再因为只想主要走野路而断开路线。野地默认“尽量避开”；旧配置勾选的类型转为“正常”，未勾选的转为“尽量避开”，原道路和标注保留。偏好影响自动选路、收藏接入与危险区绕行，危险区始终禁止通行。图片不能证明越野路段的实际通行性，也不能判断地雷位置。
- 点击地图上方 **“绘制道路”**，选择大路、小路或野地/越野，沿希望行驶的位置逐点单击。Enter / 双击 / “完成”保存，Backspace / “退一点”删除最后一个绘点，Esc 取消。保存时可填写名称、分类和备注。
- 在 **“移动 / 选路”** 模式下，直接单击地图上的道路即可选中并显示节点；拖动节点调整走向，双击道路编辑名称、类型和备注。右键道路也可编辑或删除整条道路，右键节点可删除该点。列表会同步选中对应道路。Ctrl+Z 撤销，Ctrl+S 保存。
- 绘路默认在距现有路段 8 地图像素内吸附；画野地或平行便道时可取消“吸附道路”。移动共享节点会更新同层邻接道路，接地桥头也会带动相连地面节点。相交位置需显式放置连接节点，单纯线条交叉不会自动连接。
- **道路属性中的“桥梁”** 将该条道路设为桥面层，仍保留大路 / 小路 / 野地分类与偏好。桥下辅路保持普通道路；即使交叉处节点坐标相同，两层也不连通、不会播报成可转弯路口。只对实际桥面路段勾选；桥面由多条道路组成时将它们都标为桥梁，中间相接端点保持“不接地”。
- **“起点接地 / 终点接地”** 默认不勾选，只在真实桥头或连接地面的匝道勾选。它们指道路绘制顺序的两个端点；属性窗口显示坐标，选中桥梁后地图也会标出起点、终点及接地状态。桥头可接入地面路段中部。取消“桥梁”恢复普通地面连接规则。已有路网不会自动猜测桥梁，需要手动标记；起终点或途经点若恰好落在桥上、桥下完全重叠的位置，可稍移到目标道路上再规划。
- **“地图标注 → 导入路网 / 导出路网”** 可单独共享道路和路书。导入合并已有内容、避免重复；不会覆盖目的地、危险区或收藏。资料库携带地图标识，需先切到同一张图再导入，避免坐标串图。顶部“导入配置”仍是对应地图的完整替换；导入另一张图时会先保存当前地图并自动切换，可撤销本次替换。
- 起终点和途经点会吸附到可用道路；偏移显示在路线详情中。导航终点是吸附后的道路位置，不包含未知地形中的末段通行。距离过远会拒绝规划，需要补画连接路或调整点位。
- 升级底图数据时，未改动的旧内置道路会自动替换，目的地、危险区、路书与用户新增道路保留，并备份 `project-before-map-v2.json`。如果旧内置道路曾被修改或删除，会保留原路网；可在“地图标注 → 载入内置路网”主动替换，替换前另存备份。

## 完整路线收藏

1. 规划后点击“导航 → 收藏当前路线”，保存完整路径；可在正在导航时收藏。收藏保留具体走法，重新载入时不会自动改走更短的道路。
2. 在 **“路线收藏”** 中选择路线，点击“载入”或“反向载入”，同时设置该方向的起始点与目的地；没有实时定位时也能预览全线。可再修改起始点作为返程终点。开始导航时沿路网接入当前位置附近的收藏路段，再沿剩余路径行驶；偏航重算后仍保留明确的起始点。
3. 点击 **“绘制收藏路径”**，勾选 **“贴合现有道路”**，只需按行驶顺序粗略点击起点、关键途经处和终点。绿色预览显示按当前道路类型规则和危险区规划的完整路径，道路类型取自现有路网。Enter / 双击 / “完成”保存预览中的走法。无法贴合时保留草稿并说明原因，可调整绘点或规则。
4. 不勾选贴合时，按绘点原样保存，可在绘制途中为下一段选择大路、小路或野地。勾选 **“按路径建立缺失道路”** 后，缺路部分以对应类型加入公共路网，也供普通自动规划使用；取消后仍可沿该收藏导航，但不会向公共路网添加道路。这个选择会随收藏保存，重启、反向载入和往返也不会改变它。
5. 收藏保留原走法，包含“尽量避开”类型也能载入。接入收藏和危险区局部绕行使用当前道路偏好；找不到连接道路时明确提示失败。地图重新选择终点或途经点，会退出收藏并恢复自动规划。
6. **“导入收藏”** 会先显示选项：勾选贴合则按当前路网重新计算完整路径；不贴合则保留原路径，并确认“建立公共道路”“仅用于收藏、不建立道路”，或沿用文件中各条收藏的设置。旧文件没有这些设置时必须选择是否建路。取消或贴合失败不改动当前配置，导入后仍可撤销。
7. **“导出收藏”** 保留每条收藏的完整路径、各段道路类型、名称与 ID、贴合状态、是否建立道路，以及贴合时使用的绘点；同时包含地图标识、距离比例尺和完整路书。再次导入可沿用文件设置。全局危险区、道路规则、目的地等通过顶部“导出配置”备份；道路库可另行导出共享。删除收藏保留已补入的公共道路，可在地图上另行选择删除。
8. 桥梁与桥头属性随路网、配置和收藏保存、分享。载入旧收藏时以当前道路的桥梁设置为准；若旧路径在桥面与桥下辅路交叉点直接转弯，会提示经真实桥头重新规划。收藏接入、反向载入、往返和危险区绕行同样遵守层级，不会为旧路径自动复制一条地面捷径。

## 行驶路线记录

在 **“地图标注 → 行驶路线记录”** 开启记录，只使用有效的实时小地图定位，无需先开始导航。

- **手动记录**：点击“开始记录”，行驶后点击“结束并加入路网”。记录期间在软件地图上显示橙色轨迹；新路默认为越野，与已有路网重合的部分跳过，在地面道路交叉处拆成可单独编辑的道路。桥下交叉不会自动接入桥面，只有已标注的接地桥头可以连接。
- **自动记录**：勾选“自动累计经过次数并建路”，同一路段累计达到最低次数后加入路网。默认 **3 次**，可设为 1–100 次；按独立经过累计，反向也算一次，停车和连续定位不会重复计数。新加入的相邻自动记录路段会继续接长，地面交叉处保留分段；手动修改过属性或节点的道路不再自动接长。
- 打开大地图、定位丢失、中断超过 2.5 秒或位置明显跳变时断开轨迹；有效小地图定位恢复后另起一段。用图片检验定位不会被记录。加入道路不会中断正在进行的导航或往返，可以编辑属性或撤销。
- 累计次数和未结束的手动记录按地图保存到用户配置目录的 `recordings/<地图标识>.json`，重启后保留，继续记录前仍需开启定位。“清空本地图累计次数”只重置自动累计，保留已加入的道路和手动记录。自动记录默认关闭。

## 局内大地图与快捷键

1. 在游戏中打开大地图，进入“设置 → 局内大地图 → 框选此屏幕的大地图”，框住中央地图画面，排除边框、坐标刻度和操作说明。确认后自动启用大地图功能，再开启定位。大地图与小地图使用各自的物理像素区域；调整分辨率或游戏 UI 比例后需重新框选。
2. 小地图定位正常时，不采集或匹配大地图、不读取鼠标或检查快捷键按下状态。小地图首次识别失败才探测大地图；大地图可靠且游戏在前台时才显示叠加并启用快捷键。短暂匹配失败时保留上一帧标注和最后识别率，后台继续匹配，不再跳出“识别中”；恢复小地图定位、关闭定位、切换窗口或框选区域后撤下叠加并停用快捷键。
3. 大地图显示完整淡色路线、剩余亮色路线、起始点、目的地、途经点、危险区边界、路书、收藏目的地与上次车辆位置，不显示公共路网。叠加窗口鼠标穿透，不阻止拖动、缩放和游戏操作。地形不足的高倍缩放通过先前已确认的视野跟踪；首次打开就放到极大、遮挡严重或跟踪中断时，先缩小地图重新识别。
4. 快捷键在鼠标位于大地图框选范围内时接收，操作前再次截图核准坐标；连续操作会排队，匹配暂时失败会重试，6 秒内无法核准则提示取消。可在设置中修改或留空禁用，按“保存快捷键”生效；注册冲突会显示具体操作。默认如下：

| 快捷键 | 操作 |
|---|---|
| Ctrl+Alt+N | 一键新导航：最后一次小地图车辆位置作为新起始点，鼠标位置作为目的地，清除旧途经点 |
| Ctrl+Alt+D | 修改目的地，保留起始点 |
| Ctrl+Alt+S | 修改起始点 / 返程终点 |
| Ctrl+Alt+W | 添加途经点 |
| Ctrl+Alt+A | 添加圆形危险区；半径在设置中调整 |
| Ctrl+Alt+Z | 撤销上次标注 |
| Ctrl+Alt+C | 清除路线、起始点、目的地与途经点；保留导航图标显隐状态 |

支持 Ctrl / Alt 与字母、数字、`[`、`]` 或 F1–F11 的组合。`*` 和 `Ctrl+*` 可用小键盘乘号输入，也支持主键盘 Shift+8；单独 `*` 无需 Ctrl / Alt。修改后点击“保存快捷键”，无法保存时会在窗口顶部提示；“设置 → 局内大地图”显示最近收到的快捷键及处理结果。

为兼容游戏未送达系统快捷键消息的情况，前台大地图模式也会读取所配置按键的当前状态，并与系统消息去重；按住只执行一次，松开后可再次触发。没有全局键盘钩子，也不向游戏发送输入。保存定位诊断时会附上最近一次导航快捷键的接收来源和处理状态，便于定位未响应的环节。

上次车辆位置没有时间限制，在同一地图内保留至下一次有效小地图定位；切换地图后清除。尚未取得车辆位置时，“新导航”先保存目的地，回到小地图取得定位后自动放置起始点并规划。打开大地图期间暂停车辆进度与语音；拖动和缩放地图不会移动车辆或起始点。途中修改标注后，回到小地图继续原来的去程或返程。HUD 的定位信息与主界面同步，大地图模式显示匹配置信度；未导航时重新开启定位，成功后主标题恢复“等待导航”。

## 离路与到达范围

- 不在可用道路附近时显示“请返回道路”，暂停重算并保留目的地、途经点和当前去程/返程。接近道路后自动重算；规划失败仍保留行程，驶向另一处可用道路后再试。设置中的“道路附近范围”默认 30 米，重新进入时使用略小范围，避免道路边缘反复切换。
- “导航 → 到达范围”可设为 5–1000 米，默认保留原来的 25 米。以实际设置的目标点为圆心，连续两次有效定位进入范围即算到达，不要求恰好走到道路投影终点；去程和返程均适用。往返范围重叠时，离开刚到达的范围后才会再次判定到达，避免停车时反复换向。未标定比例时按地图单位计算。

鼠标坐标通过 Windows 物理屏幕坐标读取，无需图像识别鼠标形状。录制视频只能验证地形对应关系，游戏自绘鼠标与 Windows 坐标的一致性、全局快捷键和独占全屏兼容性仍需实际运行游戏确认。

## 常规导航、拉力赛与语音

拉力赛模式在当前界面和配置中标为 WRC。它通过领航员风格的路书和语音提示，为长途运输和重复往返增加一些驾驶趣味。

- “导航 → 导航与播报”切换常规/WRC；**“查看播报”** 可切换查看同一路线的两种提示列表并试听选中条目，无需进游戏。
- **常规导航** 恢复 0.6.2 的播报方式：按实际连接的岔路逐一提示“路口直行、左转、右转、向左/右前方”，起步及经过路口后可播报“沿当前道路行驶 ×× 米”，接近路口再提示动作。取消 0.6.3 的连续路口合播和自然弯曲提醒；单纯道路弯曲或道路编号变化不触发转弯提示。**“设置 → 常规导航设置”** 保留提前距离、车速提前秒数。未画出的岔路无法从路网判断，可通过补绘改善。
- **“设置 → 通用驾驶提示”** 可开关掉头提醒，常规和 WRC 均适用。沿当前路线持续反向移动至少约 20 米、2 秒后提示“行驶方向相反，请在安全位置掉头”，同一次反向行驶只播一次，纠正方向后恢复导航。用连续位置判断，不依赖偶尔无法识别的车头图形；停车抖动和短暂倒车不会立即触发。原路线、端点、途经点和往返状态保留。
- **WRC** 使用独立曲率分析，过滤小幅折线抖动，提示左/右 1–6、直角、发卡等；**1 为慢弯，6 为快弯**。图标同时展示后续最多三条路书，语音可组合为“左三，别切，接，右六”。这只是地图几何估计，不能据此推断车辆极限速度。
- “地图标注 → WRC 路书”可添加急刹车、刹车、坡顶、颠簸、跳跃、变窄、桥梁、涉水等，勾选长弯、收紧、放开、别切或可切，也可填写自定义播报。急刹车、坡度、切弯等需人工实测标注；自动估算不凭空生成这些路况。手动弯道标注覆盖附近估算。
- 添加路书时设置正向驶入方位（北 0°、东 90°），选择双向/仅正向/仅反向。双向标注反向时交换左右和收紧/放开。方向性风险建议设为仅正向，正反向自定义文字分别填写。编辑窗口可预览并试听。
- “设置 → 常规导航设置 / WRC 路书设置”分别调整两种模式的提前量；WRC 另有连读间隔。提前量 = 基础距离 + 估计车速 × 提前秒数。单条路书可覆盖基础距离，0 沿用对应模式的全局值。“离线语音”设置声音、语速和开关。定位不可靠或中断超过 2.5 秒时停止语音；确认需要掉头时清除旧播报队列，优先提醒。
- 语音默认优先使用 Windows 系统声音，在独立子进程中枚举与合成；失败时自动使用随程序附带的默认本地语音包。也可在“离线语音”直接选择默认包，完全绕开系统语音。保留试听、语速、开关和原有声音选择。
- 默认包覆盖内置常规导航、WRC 提示和数字，不需联网、GPU 模型或额外安装。自定义路书文字未被默认包覆盖时会明确提示；任意新文字仍需可用的系统语音。定位中断取消的提示只在仍然有效时重新播报，已经播完或经过的提示不会补播。

提示分类参考 [Google/Android 官方 Maneuver 定义](https://developer.android.com/reference/androidx/car/app/navigation/model/Maneuver)中的路口动作与分岔提示；WRC 术语、弯级方向、连续提示及提前播报参考 [EA SPORTS WRC 官方新手指南](https://www.ea.com/games/ea-sports-wrc/wrc-24/news/ea-sports-wrc-beginners-guide)。本工具使用自己的路网与规则，没有接入这些产品的服务或复刻其道路数据库。

从普通道路转入越野时，会将对应提示改为“前方多少米，左转进入越野路段”等；直行跨过普通道路后重新进入越野也会提示。连续越野路段不重复播报，桥下的普通道路不作为交叉口。常规导航和 WRC 均适用，默认本地语音包已包含这些提示。

## 图标与校准

- 独立置顶导航图标可拖动、调整位置、宽高与透明度。锁定后鼠标穿透。取消锁定和调整仍在主窗口设置中操作；“移回主屏”可找回移出屏幕的图标。
- “设置 → 置顶与小地图路径”可开关主窗口置顶、路径叠加，调整路径线宽与透明度。路径跟随采集区域与地图缩放，始终鼠标穿透、不抢焦点。系统支持时排除本工具的路径窗口截图；否则定位时遮罩路径区域，避免自身路径参与匹配。
- 图标坐标使用 Windows 逻辑像素；屏幕采集区域使用物理像素。Windows 全屏优化支持在游戏“全屏”模式下叠加，但不能保证真正绕过桌面合成的独占模式。若当前全屏看不到图标，再尝试无边框全屏。游戏帧率与全屏兼容性仍需实测，参见[微软全屏优化说明](https://devblogs.microsoft.com/directx/demystifying-full-screen-optimizations/)。
- 初始距离比例由[公开地图配置](https://github.com/apollyon-sys/wardogs-calculator/tree/main/maps)的瓦片边界、每坐标单位 100 米及图像缩放/配准换算：OZETI 约 **5.3573**、BAKURANI **5.3867**、ZESTAFONA **5.1270 米/地图像素**。OZETI 保留旧图坐标，原有标注位置不变。可对每张图分别使用“地图两点校准”或直接输入比例尺复核。

## 配置与边界

道路、完整路线收藏、路书、危险区、目的地、途经点、比例尺与规则按地图保存，统一导入/导出 UTF-8 JSON。屏幕区域、语音和图标设置共用。自动保存目录为 `%LOCALAPPDATA%\WardogsNavigator`：OZETI 沿用原来的 `project.json`，另外两图位于 `maps\bakurani\project.json` 和 `maps\zestafona\project.json`；`settings.json` 记录地图选择与共用设置。更新便携包不覆盖这些用户配置。原始输入地图不被修改，运行不需要在线服务。

工具只抓取指定屏幕区域，不读取或修改游戏内存/文件，不注入游戏、不自动控制载具。截图方式本身不能保证游戏方许可；以[WARDOGS 官方政策](https://www.wardogs.com/enforcement)和游戏方答复为准。

## 已知验证边界

三张地图的公开底图裁剪样例用于验证特征匹配、比例尺、截图与路径叠加。0.6.0 另使用用户提供的 ZESTAFONA 游戏录像，验证大地图拖动、缩放以及叠加遮罩后的对应关系；私人录像不随源码分发。自动测试和录像回放不能代替游戏内即时操作和实际通行性验证。运动、遮挡、地图透明度、实时地形差异仍需游戏内验证；软件目前没有地雷或敌方单位识别功能。

朝向图形无法识别时显示“朝向未知”，可靠的地形定位仍可继续导航。单帧截图或识别失败时暂停播报、隐藏旧定位和路径，按原间隔继续尝试，恢复后沿用原行程与往返设置；无需重新选择目的地。地图资源初始化失败或截图区域小于 60 × 60 像素时会停止采集，需要先修正问题再开启定位。

定位失败后，可用“设置 → 保存定位诊断”导出本次定位期间最近的失败帧 PNG 和同名 JSON，即使随后已自动恢复也可保存。没有失败记录时保存最近处理帧；截图本身失败、没有取得图像时只保存错误 JSON，不用旧图冒充失败现场。JSON 区分所选帧的结果、接收时间与保存时的定位状态。切换地图、重新开启定位或检验新图片会重置失败记录；诊断仅保存用户选定区域。

本地自动测试与 Windows 截图测试不能替代游戏实测。实测需要确认：定位不跳点、道路可通过、危险区绕行、往返掉头提示、图标不挡操作、两种语音能听到且时机合适。

## 开发与构建

使用 Windows 10/11 x64 和 Python 3.13。项目已附运行所需地图及定位特征，源码启动和构建不需要重新下载地图。以下命令在项目根目录执行：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
.\.venv\Scripts\python.exe -m pytest -q
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

默认生成 `dist\WardogsNavigator\WardogsNavigator.exe` 和 `dist\WardogsNavigator-Windows-x64.zip`。旧程序正在使用时，可通过 `-OutputDirectory dist\release` 指定另一输出目录；启动新版前先关闭旧版，避免两个程序同时保存同一份用户配置。构建会更新所选输出目录中的程序文件。已有依赖环境时，可用 `-PythonExecutable` 指定对应的 Python 可执行文件。

地图资源及可选的重建命令见 [assets/README.md](assets/README.md)。运行程序不联网、不现场生成整个路网。重建数据是维护操作，可能改变候选路网；普通使用与打包不需要执行。

源码目录：`wardogs_nav/` 为程序，`tests/` 为自动测试，`tools/` 为地图准备和发布工具，`assets/` 为内置地图、默认路网和定位特征。贡献说明见 [CONTRIBUTING.md](CONTRIBUTING.md)。

诊断：`WardogsNavigator.exe --self-test <报告完整路径.json>` 检查打包资源、定位、道路规划、危险区、UI 与系统语音，并生成报告和本应用截图。诊断不连接或控制游戏。测试时建议设置环境变量 `WARDOGS_NAV_DATA` 指向独立目录。

运行 `python tools/export_source.py` 可在 `dist/open-source/` 生成可单独运行、测试和构建的源码副本及源码 ZIP。输出目录已存在时需用 `--output dist/新目录/WardogsNavigator` 选择新目录，工具不会覆盖已有仓库。
