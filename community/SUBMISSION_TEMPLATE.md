# 配置包说明模板

将下面的内容复制到自己的配置包 README.md，替换所有占位文字，并删去未提供的文件条目。该文件只是填写模板，不是可导入的配置。

~~~markdown

# 配置名称

| 项目 | 内容 |
|---|---|
| 地图 | OZETI / BAKURANI / ZESTAFONA，保留实际的一项 |
| 作者 | @你的GitHub用户名，附个人主页链接 |
| 协作者或原作者 | 没有则写“无”；有则保留姓名/账号与来源链接 |
| 适用程序版本 | 例如 0.5.1；只写实际验证过的版本 |
| 游戏版本与验证日期 | 已知版本及 YYYY-MM-DD；未知项明确写“未知” |
| 配置版本 | 例如 1.0；更新时递增并写变更记录 |
| 用途与覆盖范围 | 例如补绘道路、固定补给线、拉力赛路书；描述具体地点 |
| 实测状态 | 未实测 / 部分实测 / 已实测，并说明实际范围 |
| 车辆与限制 | 测试车辆类型、方向、桥梁、坡度、宽度等；未知项不要猜测 |
| 许可与来源 | 原创部分 Apache-2.0；基于其他配置时填写来源与许可 |

## 文件和导入

- [路网](roads.json)：地图标注 → 导入路网；包含哪些道路和路书。
- [路线收藏](routes.json)：路线收藏 → 导入收藏；列出路线名称与起终点。
- [完整配置](project.json)：顶部 → 导入配置；会替换目标地图配置，请先备份。

填写推荐的收藏导入选项：是否重新贴合现有道路；不贴合时是否建立公共道路。如果希望严格保留投稿的路径，说明选择“不重新贴合”；如果只让该收藏使用缺路段，说明选择“不建立道路”。

## 实测和已知限制

描述测试过的具体路段、车辆、方向及结果；未测试的范围也写明。无需在软件中设置道路确认状态。危险区须注明观察时间及适用条件，不能据此保证当前对局没有地雷或敌人。

## 变更记录

- YYYY-MM-DD：首次提交；说明新增内容。

## 投稿前确认

- 文件由应用导出，仍能在对应地图成功导入。
- 未删除完整路径、分段类型、路书及贴路/建路选项等导出字段。
- 已检查路书文字、目的地和危险区中没有不想公开的信息。
- 没有打包本机 settings.json、整个用户数据目录、账号凭据或原始定位诊断。
- 保留原作者与来源；有权按声明的许可分享本次贡献。
~~~
