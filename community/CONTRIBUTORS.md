# 社区配置贡献者

这里记录已合并的道路、路线、路书、实测修正及共享说明贡献，不以代码行数衡量价值。GitHub 自动贡献统计之外，这份名单和每个配置包的 README 都会保留作者署名。

目前尚无已合并的社区配置投稿；不预填虚构贡献者。

| 贡献者 | 贡献内容与配置链接 | 合并 PR |
|---|---|---|

维护者在实际合并后登记，或在将要合并的同一 PR 中确认登记内容。多人共同贡献分别署名，改进已有配置保留原作者。每个账号可记录多项贡献，不必重复创建同名条目。

GitHub 自动统计需要保留正确的提交作者及其关联邮箱，并将提交合并到默认分支；Contributors 图表仅展示前 100 位。列表显示还可能有延迟。参见 [GitHub 说明](https://docs.github.com/en/repositories/viewing-activity-and-data-for-your-repository/viewing-a-projects-contributors)。

获得这里的署名不会自动获得仓库写入或合并权限。
